Périodes de notation

Découpage de l’année en trimestres ou semestres. Les dates doivent couvrir toute l’année scolaire active, sans trou ni chevauchement.

Des évaluations existent pour cette classe : le type de période (trimestre / semestre) ne peut plus être modifié. Les périodes qui contiennent déjà des évaluations ne peuvent plus être déplacées.

Type de période
Répartition 3 trimestres 2 semestres Changer le type recalcule les périodes (aucune évaluation ne doit exister sur cette classe). Lecture seule (personnel pédagogique).
